# JS Calculator App
- preview




## About

The JS Calculator App is a simple web-based calculator built using JavaScript, HTML and CSS. It aim replicating the basic functions and design of a standard iphone calculator.

## The app allows users to

- Perform basic arithmetic operations: addition, subtraction, multiplication, and division.

- Clear all inputs (AC button).

- Delete one digit at a time.

- Display the selected operator on the screen.



## How It Works

Users click number buttons to input values.

Users select an operator (+, −, ×, ÷, %).

Pressing = gives the result.

Pressing AC resets the calculator.

Pressing DEL removes one digit at a time.

If a new number is entered after =, the calculator automatically starts a new calculation.
